## Commit conventions

See CONTRIBUTING.md's "Commits and AI attribution" section — no
`Co-Authored-By`/`Assisted-by` trailer naming a model, ever. Disclose AI
assistance in prose in the commit body or PR description instead.

## Pushing to remotes

Never run `git push` (including `--force`) on any remote in this repo
unless the user explicitly approves that specific push in that turn. A
prior approval does not carry over to later pushes — ask again each time.
When a push is needed, state the exact command and wait for explicit
go-ahead instead of running it.
