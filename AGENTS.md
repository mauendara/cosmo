# Agent instructions

This file exists for any AI agent or coding assistant contributing to this
repository, regardless of tool.

## Commit conventions

See [CONTRIBUTING.md](CONTRIBUTING.md)'s "Commits and AI attribution"
section — no `Co-Authored-By`/`Assisted-by` trailer naming a model, ever.
Disclose AI assistance in prose in the commit body or PR description
instead.

## Everything else

Follow [CONTRIBUTING.md](CONTRIBUTING.md) in full: setup, `./check.sh`, and
the test-enforced architectural boundaries. There is no separate agent-only
policy — the same rules apply whether the contributor is human or not.
